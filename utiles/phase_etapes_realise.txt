1️⃣7️⃣ Statut de Départ (TypeDepart)

id (PK)
nom (ex: "Transfert", "Exclusion", "Abandon", "Fin de contrat", "Démission")
description

1️⃣8️⃣ Historique de Départ (Depart)

id (PK)
user_id (FK → User) - pour Enseignant/Admin
etudiant_id (FK → Étudiant) - pour Étudiant
type_depart_id (FK → TypeDepart)
date_depart
raison_detail (texte libre : détails supplémentaires)
document_justificatif (chemin fichier, optionnel)
date_enregistrement
enregistre_par_id (FK → User, qui a enregistré le départ)


Logique :

Pour chaque Étudiant, Enseignant ou Admin qui quitte, on crée un enregistrement Depart
Cela permet de savoir qui a quitté, quand, et pourquoi
L'entité reste en base de données (pour l'historique) mais est marquée comme inactive
